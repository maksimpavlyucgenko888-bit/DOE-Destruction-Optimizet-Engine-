# DOE-Destruction-Optimized-Engine-
My own engine where you can do anything with props and infiniti build


Control:
WASD - move
/ Space - jump
/ 1,2,3,4,5 - spawn props
/ R - reload everything
/ LMB,E - grab\E
/ T - Destroy every props

You can download version in realease just click 1 tag button
